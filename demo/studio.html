What "seam-safe" does

Upstream compact() packs tiles as tight as possible but may reorder them, so the chart you put next to the number it explains can end up somewhere else. Seam-safe is a shelf reflow that preserves reading order: tiles are sorted by row then column, then packed left-to-right, wrapping to a new row only when the current one is full. The result is as tight as compact, but tile n always stays after tile n-1. Use Compact when you don't care about order, and Pack when you want the fewest rows possible.

Honest numbers

Every counter is computed from the live layout with the library's own measureLayout(), never from the plan. Press Preview to see the target outlines before committing, and watch the deltas after applying — a negative row count is good, a positive one is not.
